Expense Tracker

A simple Python application for recording and tracking personal expenses.

Features

- Add expenses
- View recorded expenses
- Calculate total spending
- Store expense descriptions and amounts

Technologies

- Python
- Lists
- Dictionaries
- Loops
- Conditional statements

How to Run

Open the project in VS Code and run:

python expense_tracker.py

Example

The program allows the user to enter an expense such as:

- Lunch — $5
- Transport — $3
- Shopping — $20

It then calculates the total amount spent.

Purpose

This project demonstrates basic Python programming and can be extended into a more advanced expense-management application.
